XTP Tutorials
=============

The tutorials are Jupyter notebooks in ``xtp-tutorials`` (installed to
``share/votca/xtp-tutorials``):

-  ``DFTGWBSE_ENERGY``: DFT and GW-BSE for a single molecule with ``xtp_tools``.
-  ``single_point`` and ``geometry_optimization``: the same with the Python
   (ASE) interface; they are built only if the Python bindings are.
-  ``QMMM_GROMACS``: the full workflow for an MD morphology, from mapping to
   site energies, couplings and embedded GW-BSE (for LAMMPS input see
   :doc:`../xtp/workflows_and_calculators`).
-  ``TRANSPORT``, ``STOCHASTIC_NETWORK`` and ``LAMMPS_KMC``: charge and
   exciton transport (KMC, time of flight, graph random walks, stochastic
   network models).
